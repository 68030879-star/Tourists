## 3. พจนานุกรมข้อมูล (Data Dictionary) ของ `c:\Users\Administrator\Downloads\tourists_all(1).csv`

ข้อมูลหลังจากทำความสะอาดแล้วมีทั้งหมด 20,317 แถว ตารางต่อไปนี้แสดงชื่อคอลัมน์ ชนิดข้อมูล คำอธิบาย และจำนวนค่าว่างของแต่ละคอลัมน์

| คอลัมน์ | ชนิดข้อมูล | คำอธิบาย / ค่าที่เป็นไปได้ | ค่าว่าง |
| --- | --- | --- | ---: |
| `date ` | ตัวเลข | แสดงวันที่และเวลาที่บันทึกชุดข้อมูลสถิตินักท่องเที่ยว ในรูปแบบ Timestamp (เช่น ⁠2015-01-01T00:00:00⁠) ซึ่งระบุจุดเริ่มต้นของช่วงเวลาในการเก็บข้อมูลนั้น ๆ | 0 |
| `continent ` | ข้อความ | บุชื่อทวีปที่เป็นต้นทางของนักท่องเที่ยว เช่น ทวีปแอฟริกา (⁠Africa⁠) เพื่อจัดกลุ่มข้อมูลในระดับมหภาค | 0 |
| `Region ` | ข้อความ | ระบุภูมิภาคย่อยภายในทวีป เพื่อแบ่งโซนพื้นที่ให้ละเอียดขึ้น เช่น แอฟริกาเหนือ (⁠North africa⁠) หรือแอฟริกาใต้สะฮารา (⁠Sub-Saharan Africa⁠) | 0 |
| `Country ` | ข้อความ | ระบุชื่อประเทศต้นทางของนักท่องเที่ยวอย่างเจาะจง เช่น โมร็อกโก (⁠Morocco⁠), แอฟริกาใต้ (⁠South Africa⁠), หรือเอธิโอเปีย (⁠Ethiopia⁠) | 0 |
| `Number ` | ตัวเลข | แสดงตัวเลขจำนวนของนักท่องเที่ยวจากประเทศนั้น ๆ ที่เดินทางเข้ามาในช่วงเวลาที่กำหนด (เช่น ⁠498⁠ หรือ ⁠5,154⁠) | 0 |
